Hold the globe key. Yap. Done.

Private, on-device dictation for macOS. For certified yappers.

Everything stays on your Mac Apple's on-device speech engine plus your own local LLM for cleanup. No cloud, no account, no telemetry, no word limits, no subscription. Ever.
Fast because it starts early Audio streams into the recognizer while you are still talking, so text lands the moment you let go.
Your words, not the AI's Cleanup strips the ums and fixes punctuation behind editable prompts, with guards that fall back to your raw words. History shows raw and cleaned side by side.
Knows where you are typing Casual in Slack, formal in Mail, verbatim in the terminal. Select text and speak an instruction to rewrite it.
git clone https://github.com/angad729/yapping.git
cd yapping

Download GitHub

Network connections: localhost (your Ollama) and, only when you click Check for Updates, the GitHub API. That is the whole list.
