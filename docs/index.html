features

Everything a dictation tool should be.
Nothing it shouldn't ask for.

Built from a deep dive into what users of every major dictation app complain about: clouds, subscriptions, black-box AI, and mangled names.

🔒

On-device everything

Apple's SpeechAnalyzer for recognition, your own local Ollama model for cleanup. No account, no cloud, no word limits, no subscription. Ever.

⚡

Starts before you finish

Audio streams into the recognizer while you are still talking, so the text lands the moment you release the key.

📚

Personal dictionary

Your names, jargon, and acronyms bias the speech engine itself. It's Angad, not "on God".

🎨

Styles per app

Casual in Slack, formal in Mail, verbatim in the terminal. Every prompt is editable; nothing about the rewriting is hidden.

✏️

Edit by voice

Select text, hold the key, say "make this more formal". The selection is rewritten in place, or left untouched if the model fails.

👀

Transparent cleanup

History shows raw and cleaned text side by side. If cleanup ever changes your meaning, you will see it, and your raw words always win on doubt.

how it works

Three seconds, start to sentence.

Hold

Press and hold the globe key anywhere. The bars above your Dock start dancing with your voice.

Yap

Say what you mean, ums and all. Correct yourself mid-sentence; only the final version survives.

Done

Release. Clean text appears at your cursor, matched to the tone of whatever you were writing.

faq

Questions certified yappers ask.

What does it need to run?

macOS 26 on Apple Silicon. For the optional cleanup pass, install Ollama and pull a small model (gemma3:4b, about 3 GB). Without Ollama, yapping pastes accurate raw transcripts.

Why does macOS warn me when I open the downloaded app?

Releases are not notarized, which requires a paid Apple Developer membership. Allow the app once under System Settings, Privacy & Security, or skip the warning entirely by building from source with make install. The code is public; read it first if you like.

Is my audio or text stored anywhere?

Your last 20 dictations are kept in a local history file so you can inspect what cleanup changed, and you can clear it any time. Audio is never written to disk; it streams from the mic straight into the on-device recognizer.

Does it work in every app?

Anywhere you can type: browsers, editors, chat apps, terminals. Terminals and code editors get verbatim mode by default so cleanup never touches your commands.

Why the globe key?

It sits in the corner doing almost nothing, your thumb already knows where it is, and holding it feels like a walkie-talkie. Set "Press globe key to: Do Nothing" in System Settings and yapping takes it from there.
